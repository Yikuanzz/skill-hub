# 头条号「资讯类」图文爆款逻辑调研

> 调研时间：2026-11-10
> 样本：今日头条「热点 / 财经 / 国际 / 娱乐 / 军事 / 科技」6 个频道最新内容（各约 15 条，共 75 条标题）+ 热点频道 4 篇全文 + 全站热榜 50 条 + 平台官方规则与公开数据
> 方法：RSSHub（`/toutiao/channel/:category`）抓取频道流，`m.toutiao.com/i{id}/info/` 取正文，官方帮助中心/社区规范与平台公开报道做交叉验证

## 0. 先给结论（如果只记 10 条）

1. **头条是「信息流生意」，不是「文章生意」。** 标题 + 封面共同决定点击率，开头 100 字决定完读率，结尾决定互动率；三者是三个独立的关卡。
2. **资讯类在头条已经分成两种生态**：机构媒体做「直陈式快讯」，自媒体做「故事化解读」。前者拼时效与信源，后者拼角度与情绪，混着做最容易两头不讨好。
3. **标题的第一功能是「让人产生信息缺口」，不是「概括全文」。** 但缺口必须由正文填上——官方把「隐瞒关键信息、故弄玄虚」明确列为标题党。
4. **最强的标题结构是「具体主体 + 冲突/反差 + 具体数字/后果」**，3 个元素至少占 2 个；纯形容词堆砌的标题在算法里没有辨识度。
5. **封面是第二标题，不是配图。** 封面负责「谁 / 在哪 / 什么画面」，标题负责「发生了什么 / 为什么」，两者互补而不复述。
6. **资讯类正文的最优结构是「钩子—锚点—展开—收束」**：前 60–100 字给最硬的信息，250 字内补全 5W，中段每 300–400 字一个小标题，结尾给判断或问题。
7. **配图不是装饰，是阅读节奏器。** 3–6 张、每 300–500 字一张、首图承担封面职能，图表/截图/现场图交替使用。
8. **平台在 2025 年后明确押注「优质深度」**：头条用户严肃思辨类内容消费占比 44%（行业均值 14%），优质深度图文阅读量同比增长近 3 倍，并给深度文章单独设冷启动流量池。这利好「有信息增量」的资讯解读，不利好搬运汇编。
9. **资讯类最大的合规风险不是标题党，而是资质**：未取得互联网新闻信息服务许可，不得发布/评论时政、经济、军事、外交及社会突发事件。个人号做「新闻」而非「知识/生活/产业解读」，随时可能被限流或封号。
10. **可复制的不是某一篇爆款，而是一条流水线**：热榜选题 → 三平台验证 → 10 个标题备选 → 3 张封面备选 → 固定结构成稿 → 高峰发布 → 黄金 1 小时干预 → 三段归因复盘。

## 1. 平台机制：为什么标题和封面能决定生死

### 1.1 分发链路

```
发布 → 审核/消重 → 内容理解（标签、实体、质量分）
     → 冷启动小流量池（标签匹配用户）
     → 看点击率 / 完读率 / 互动率 / 负反馈
     → 达标则进入更大流量池，不达标则停止推荐
```

- 今日头条推荐系统的输入是三类特征：**内容特征、用户特征、环境特征**（时间/地点/场景）；点击率、阅读时长、点赞、评论、转发都是可量化的优化目标（今日头条算法公开分享，极客公园整理）。
- 系统会**过滤停留时间短的点击以打击标题党**，对热门内容动作降权，对「推荐了但没人点」的类别/关键词/来源做权重惩罚。这意味着：**骗点击的短期收益会被长期账号权重吃掉。**
- 行业普遍观察到的冷启动量级是 **200–1000 次曝光**；2025 年头条官方则明确为深度图文设置「冷启动流量池」，说明平台愿意给长文更多试错机会，但前提是内容被判定为「优质深度」。

### 1.2 四个关键指标（行业经验值，非官方承诺）

| 指标 | 健康区间 | 低了说明什么 | 优先改什么 |
|---|---|---|---|
| 点击率 | 4%–8% | 标题无辨识度 / 封面无主体 / 标签不精准 | 标题 + 封面 + 领域关键词 |
| 完读率 | 30%–50% | 开头没钩子 / 段落太长 / 信息密度低 | 前 100 字 + 小标题 + 配图节奏 |
| 互动率 | 1%–3% | 没有可讨论的观点 / 结尾没提问 | 争议点 + 开放式结尾 |
| 粉丝转化 | 0.5%–2% | 单篇价值感不足 / 没有人设 | 系列化 + 作者视角 |

> 用法：不要用绝对值判断好坏，用**同账号同领域近 30 篇的中位数**做基线，看单篇是高于还是低于基线。

### 1.3 2025–2026 的平台风向

- 2025 年 12 月今日头条生机大会宣布把「优质深度」作为核心内容战略：头条用户在资讯、公共议题等严肃思辨类内容上的消费占比达 **44%**（互联网大盘 14%）；优质深度图文阅读量同比增长近 **3 倍**；每日超半数日活用户接触到优质深度精选内容。
- 首发激励计划（2025-08-28 升级）明确 5 条质量标准：**首发时效、原创深度、信息增量、创作规范、用户价值**；符合条件最高 5 倍补贴，且要求正文字数 >100 字。
- 结论：**「快讯 + 一句解读」的中间态最危险**——既没有机构的时效与信源，也没有深度内容的信息增量。

## 2. 样本观察：资讯类内容其实有四种，不是一种

对 6 个频道 75 条标题的观察（2026-11-09 抓取）：

| 频道 | 主流形态 | 标题特征 |
|---|---|---|
| 热点 | 故事化资讯 / 情绪解读 | 冲突、数字、后果、身份标签 |
| 财经 | 机构快讯 + 财富故事 | 两极：一行电讯 vs「首富/骗局/情妇」叙事 |
| 国际 | 地缘解读 / 人物故事 | 设问、反差、「没想到」「被孤立」 |
| 娱乐 | 人物命运叙事 | 年龄 + 处境 + 反转 |
| 军事 | 军事科普 + 情绪评论 | 「最怕的不是…」「一旦…」 |
| 科技 | 机构稿比例最高 | 直陈式：「X 发布」「Y 涨近 7%」 |

由此可以把资讯类拆成 4 种产品，各自适配不同团队：

| 类型 | 字数 | 核心能力 | 标题策略 | 封面策略 | 适合谁 |
|---|---|---|---|---|---|
| **A 快讯** | 80–300 | 时效、信源、准确性 | 直陈 5W，少修饰 | 无图或单图现场 | 机构媒体、有资质的号 |
| **B 汇编/早报** | 800–1500 | 信息筛选、结构化 | 「N 条」「一文看懂」「今日必读」 | 大字报/信息图 | 运营型团队 |
| **C 解读** | 1500–2500 | 背景、因果、判断 | 设问 + 反常识 + 影响 | 人物/现场 + 图表 | 有领域积累的作者 |
| **D 故事化资讯** | 2000–3000 | 叙事、细节、情绪 | 人物 + 命运 + 反转 | 人脸特写 + 强对比 | 自媒体（风险最高） |

**关键判断**：D 类流量最大、合规风险也最大。平台《社区规范》明确把「旧闻新发」「编造故事」「标题与内容不符」列为违规；没有一手信息源时，D 类很容易滑向「真假掺半」。

## 3. 标题逻辑

### 3.1 标题到底在做什么

信息流里用户给一条内容的决策时间约 **1–1.5 秒**。标题要在这 1 秒内完成三件事：

1. **识别**：这是不是我关心的领域？（领域关键词）
2. **缺口**：我还不知道什么？（悬念/反差/数字）
3. **收益**：点开能得到什么？（信息、情绪、谈资、方案）

三者缺一，标题就会「看起来还行，但没人点」。

### 3.2 八个高频母题（附真实样本）

> 以下标题均来自 2026-11-09 头条频道样本，仅作结构分析，不代表推荐其价值观或真实性。

| 母题 | 结构 | 样本 |
|---|---|---|
| **1. 反差/递进** | 「比 A 更 X 的是 B」 | 《比学历贬值恐怖的事情出现了！中国正在失控的考研考公内卷在加剧》<br>《比燃油车销量下滑更恐怖的是：中国正在失控的汽车价格战持续升级》 |
| **2. 数字 + 后果** | 具体金额/人数 + 谁受害 | 《中国首例1000亿骗局！上百万人血本无归，凶手却每天花两万养情妇》 |
| **3. 时间 + 节点** | 精确时刻 + 重大动作 | 《4时24分准时起飞，中国凌晨达成重大一射，多国宇航员等待上天宫》 |
| **4. 人物 + 反转** | 名人 + 没想到 + 牵连 | 《黄仁勋没想到，自己的私生活风波，意外把36岁女儿“拖入泥潭”》 |
| **5. 设问/解释** | 为什么 A 却 B？ | 《为什么马斯克一堆女友却不影响市场，而黄仁勋出轨，市场就塌方？》 |
| **6. 身份/地域代入** | 「在 X 的华人/从业者」+ 反常识 | 《在蒙古工作的华人感慨：不要听媒体吹牛，蒙古相当于我国二线城市》 |
| **7. 清单/避坑** | 数字 + 规则 + 利益 | 《建议大家：今明两年，买房要坚持“买2、买小、不买4”，都是经验》 |
| **8. 直陈快讯** | 主体 + 动作 + 数据 | 《港股PCB概念股走强 建滔积层板涨近7%》 |

### 3.3 可复用的 6 个句式模板

```
① 反差式：[大众认知 A] 的人，为什么在 [具体场景] 输给了 [小人物 B]？
② 递进式：比 [已知坏消息] 更严重的是，[未被注意的结构性问题]
③ 数字式：[主体] 做了 [动作]，[具体数字] 人 / [金额] 受影响
④ 设问式：为什么 [反常现象]？答案藏在 [线索] 里
⑤ 身份式：[跟你一样的人] 在 [时间/地点] 发现：[反常识结论]
⑥ 清单式：[人群] 注意：[N] 个 [坑/信号/变化]，第 [k] 个最容易被忽略
```

**组合原则**：一条标题里最多放 **2 个母题**。三个以上会变成信息堆砌，用户读不完。

### 3.4 字数、标点与用词

| 项 | 建议 | 说明 |
|---|---|---|
| 字数 | **20–28 字**为主 | 后台上限通常 30 字；快讯可 12–18 字；超过 30 字移动端会截断 |
| 标点 | 0–2 个 | 「！」「？」「：」各最多 1 个；不要「！！？？」 |
| 数字 | 尽量用阿拉伯数字 | 「1000亿」比「一千亿」更快被扫到 |
| 人称 | 「你/我/他」至少出现一个 | 拉近距离，但资讯类慎用「我」（易被判故事化） |
| 关键词 | 前 10 字放核心实体 | 算法与用户都先扫前半句 |
| 禁用 | 震惊、必看、速看、不转不是、最、第一、国家级 | 官方明确列为夸张/极限用语 |

**标点的高级用法**：
- `：` 用于「观点 + 事实」的分层：`XX 终于表态：一句话，信息量很大`
- `“”` 用于给对方贴标签：`“地表最强小三”`——但容易滑向低俗，资讯类慎用
- `？` 用于把结论变成待解问题，但正文必须真的回答

### 3.5 标题自检 7 问

1. 去掉形容词，还剩具体信息吗？
2. 标题里的数字/人名/地点，正文能一一对应吗？
3. 有没有一个「我非点不可」的缺口？
4. 是否出现了领域关键词（让算法认出你是谁）？
5. 是否隐含了正文没有的结论？（标题党红线）
6. 读起来像人话，还是像公文/机器翻译？
7. 把标题给一个不关心该领域的人看，他能复述发生了什么吗？

### 3.6 官方红线（原文要点）

《今日头条社区规范》「标题低质」：

- **标题夸张**：夸张式（夸大感受/范围/结果/程度）、悬念式（滥用转折、隐藏关键信息、故弄玄虚）、强迫式（挑衅恐吓、强迫建议）。
- **标题与内容原意有偏差**：歧义、无中生有（捏造人/物/情节/言论）、滥用名称或题材不明确、**封面与标题不符**。
- **标题不规范**：错别字、语病、滥用标点、语义不通。

> 注意：「封面与标题不符」被写在标题条款里——说明平台把**标题 + 封面当作一个整体**审核。

## 4. 封面逻辑

### 4.1 封面在信息流里的真实角色

- 单图：标题在左/上，封面在右/下，二者是一个视觉单元。
- 三图：三张缩略图并排，**信息量更大，但也更容易糊**；三张必须同风格、同色调、同主体逻辑。
- 无图：纯文字卡片，靠来源权威和标题硬度，适合快讯。

**封面要回答的问题**：这条内容「关于谁、发生在哪、画面是什么」。
**标题要回答的问题**：「发生了什么、为什么和我有关」。
两者**不要复述**。封面已经写了「黄仁勋」，标题就不用再重复三遍名字。

### 4.2 尺寸与安全区（实操口径）

- 头条图文后台封面设置提供 **无图 / 单图 / 三图** 三种模式。
- 单图与三图在信息流中会被裁切，**没有一张图能保证全尺寸原样展示**，所以：
  - 原图按 **横图 16:9 或 3:2** 准备，分辨率不低于 **1280×720**；
  - 主体（人脸、logo、核心物体）放在画面**中间 60% 安全区**；
  - 重要文字离边缘至少 8%；
  - 三图时三张保持同一比例，否则并排会高低不齐。
- 体积控制在 **2MB 以内**，宽度 1080–1280 足够，过大反而被压缩得失真。

> 网上流传的「头条封面 1175×667 / 1024×678 / 4:3」都是不同位置、不同时期的经验值。**不要记死数字，记「横图 + 主体居中 + 留裁切余量」**。

### 4.3 五种封面范式

| 范式 | 适用 | 做法 | 风险 |
|---|---|---|---|
| **现场抓拍** | 突发、事故、现场 | 选有人、有动作、有环境信息的一帧 | 血腥/隐私要打码 |
| **人物特写** | 人物、国际、娱乐 | 半身/脸部占 1/3 以上，眼神看向标题 | 肖像权、表情包化 |
| **对比拼图** | 盘点、前后变化、A vs B | 左右/上下分屏，中间加一条细线 | 拼接痕迹重会显低质 |
| **大字报** | 政策、通报、数据发布 | 纯色底 + 1 行 8–12 字大字 + 小字来源 | 字太多、颜色太杂 |
| **图表/截图** | 财报、榜单、聊天记录 | 裁到核心区域，加一句图注 | 带其他平台水印/二维码=违规 |

### 4.4 封面的「三秒测试」

把封面缩到手机信息流大小（约 300px 宽），问：

1. 3 秒内能看出主体吗？
2. 主体和标题是互补还是重复？
3. 在白色/浅灰背景的信息流里，它跳出来了吗？
4. 有没有文字被裁、脸被切、水印压脸？
5. 换成竞品账号发，会被认为是同一调性吗？

### 4.5 封面红线（官方）

- 封面图与内容主体**完全不相关**，或结合标题易使读者误解。
- 图片与内容毫无关联且质量差；不良诱导、偷拍、易引发低俗联想的同框图。
- 带其他平台水印、二维码、联系方式（属「恶意营销」）。
- 未经授权使用他人图片（属「抄袭侵权」）。

## 5. 行文结构

### 5.1 通用骨架：钩子—锚点—展开—收束

| 段落 | 字数 | 任务 | 写法 |
|---|---|---|---|
| **钩子** | 60–100 | 让手指停下 | 一句结论 / 一个数字 / 一个场景 / 一句原话 |
| **锚点** | 100–200 | 补全 5W，建立可信度 | 时间、地点、人物、发生了什么、信源 |
| **展开** | 1200–2000 | 给信息增量 | 3–5 个小标题，每个 300–400 字 |
| **收束** | 100–200 | 给判断或问题 | 金句 / 影响 / 开放式提问 |

**开头 7 式**（按资讯类适配度排序）：

1. **结论前置**：`先说结论：这次降价的真正原因，不是库存。`
2. **数字冲击**：`423 万人报名，只招 3.5 万。`
3. **场景切入**：`昨天下午，杭州一位店主把最后一批货搬上了货车。`
4. **引语开场**：`“我们也没想到会这么快。”一位接近交易的人士说。`
5. **反差设问**：`为什么越努力的人，反而越容易被裁？`
6. **时间锚点**：`11 月 8 日深夜，一封内部邮件改变了英伟达的舆论走向。`
7. **利益相关**：`如果你明年打算买房，这条政策会直接影响你的首付。`

**开头 3 不要**：
- 不要「随着……的发展」；
- 不要先讲行业史；
- 不要在 100 字内出现两个以上陌生概念。

### 5.2 四种结构模板

#### A. 快讯型（80–300 字）

```
[时间/地点] + [主体] + [动作] + [关键数据]。
[一句背景：为什么重要]
[一句影响：对谁有影响]
[信源]
```

样本（真实）：

> 11月10日，截至发稿，建滔积层板（01888.HK）涨6.88%、广合科技（01989.HK）涨6.21%、胜宏科技（02476.HK）涨5.89%。

特点：**没有形容词**，靠时效和准确性取胜。适合机构号、财经号；个人号发这个拼不过机构。

#### B. 汇编/早报型（800–1500 字）

```
导语：今天最值得关注的 N 件事
01 [事件] —— 一句话事实 + 一句话解读
02 ...
03 ...
结尾：今天需要盯的一个信号
```

要点：
- 每条 **不超过 120 字**，事实与解读用不同字体/颜色分开；
- 编号必须连续，不要「一、1、（1）」混用；
- 每条给信源，避免「据悉」。

#### C. 解读型（1500–2500 字）

```
钩子：一个反常识结论
锚点：事件 + 时间线
01 发生了什么（事实层）
02 为什么会发生（原因层，2–3 个变量）
03 接下来会怎样（三种情景）
04 对普通人意味着什么（影响层）
收束：我的判断 + 一个开放问题
```

要点：
- 每个小标题都是**一个判断**，不是「背景介绍」；
- 至少给 **1 个别人没说的角度**（数据、历史对照、产业链位置）；
- 三种情景要写清楚「触发条件」，不要模棱两可。

#### D. 故事化资讯（2000–3000 字，高风险）

```
金句开场
01 场景/人物登场
02 转折（冲突出现）
03 细节（数字、对话、时间点）
04 代价/后果
05 反思（作者视角）
收束：金句 + 互动
```

样本结构（《31岁女工程师猝死轰动全网，AI已经开始杀人了！》）：

- 开头金句：「不要把你的生命，托付给一段毫无温度的代码。」
- `01`–`06` 编号分段，每段一个信息节点；
- 用「时间 + 地点 + 具体数字」堆真实感（31 岁、27 万条消息、400 毫克、158 次担忧）；
- 中段插入第二、第三个案例，把单一个案扩展成趋势；
- 结尾落到「平台责任 + 个人选择」，再引导点赞转发。

**必须做的三件事**：
1. 开头或结尾标注信源与「个人观点」；
2. 区分「已确认事实 / 媒体转述 / 网络猜测」；
3. 不用真实姓名编造对话。

### 5.3 段落与节奏

- 每段 **1–4 行**（手机屏 3–5 行就会疲劳）；
- 每 **300–400 字**一个小标题；
- 小标题用**动词或判断**开头：`降价潮开始了` / `谁在买单` / `真正的风险在明年`；
- 每 500 字左右一个「情绪转折」：真相、反例、数字、引语；
- 长文每 800–1000 字插一张图，短图文 3–6 张。

### 5.4 结尾 4 式

| 类型 | 写法 | 适用 |
|---|---|---|
| **判断式** | 「短期看……，长期看……，真正的变量是……」 | 解读、财经 |
| **提问式** | 「如果是你，会怎么选？」 | 社会、情感 |
| **行动式** | 「接下来 3 天，重点盯这三个信号」 | 政策、市场 |
| **金句式** | 一句可被截图转发的话 | 人物、评论 |

> 资讯类最忌讳结尾「以上就是全部内容，欢迎关注」。要么给判断，要么给问题。

## 6. 图文配置

### 6.1 数量与位置

| 文章类型 | 配图数 | 位置 |
|---|---|---|
| 快讯 | 0–1 | 文末或数据处 |
| 汇编 | 3–6 | 每个板块 1 张 |
| 解读 | 4–8 | 开头 1 张、每个小标题后 1 张、数据处 1 张 |
| 故事化 | 3–6 | 场景、人物、转折、结果各 1 张 |

**首图 = 封面**。首图选错，后面再好的图也救不回来。

### 6.2 图片类型搭配

- **现场图**：给真实感，优先；
- **人物图**：给情绪，注意肖像权；
- **图表**：给可信度，必须标数据来源与时间；
- **截图**：给证据，裁掉无关 UI，隐私打码，不能带其他平台水印；
- **信息图**：给结构，适合「N 个变化」「时间线」。

### 6.3 图片规范

- 宽度 1080–1280，单张 <2MB；
- 横图优先，竖图连续两张会打断阅读；
- 图注写「信息增量」，不要写「图片来源于网络」；
- 同一篇文章色调尽量统一（冷/暖、明/暗）；
- 不用拼图软件默认边框、不用表情包当新闻配图。

### 6.4 版权

- 首选：平台「热点图库」、自有拍摄、官方通稿图；
- 次选：明确 CC 授权/可商用图库，保留授权记录；
- 禁止：搜索引擎直接下载、带水印图、他人社交平台照片；
- 官方规则：未经授权使用他人著作权内容（含洗稿、拼凑）属「抄袭侵权」。

## 7. 从选题到发布：一条可执行的流水线

### 7.1 选题（30–60 分钟）

1. **热榜筛选**：只看**持续上榜 ≥4 小时且排名前 8** 的话题（三分钟热度不值得跟）。
2. **三平台共振**：微博热搜前 15 + 抖音热榜前 10 + 头条热榜前 8，同时出现 = 黄金窗口，24 小时内出稿。
3. **评论区挖题**：找同领域 50 万+ 阅读、8000+ 评论的爆款，按「最新」读前 50 条，记录高频问句——这些就是下一篇的选题。
4. **判断能不能做**：
   - 我有信源吗？
   - 我有别人没有的角度吗？
   - 我的账号有资质吗？（时政/财经/健康尤其注意）

### 7.2 标题（20–30 分钟）

1. 先写 **10 个**备选（每个母题至少 1 个）；
2. 删到 **3 个**（不同母题，避免同质）；
3. 用 3.5 的 7 问筛选，留 **1 个**；
4. 发布后 2 小时看点击率，低于账号基线 30% 再考虑改标题（修改可能影响推荐，慎用）。

### 7.3 封面（15 分钟）

1. 准备 3 张候选：现场图 / 人物图 / 图表；
2. 缩到 300px 宽做「三秒测试」；
3. 检查主体是否在中间 60% 安全区；
4. 三图模式检查三张比例、色调是否一致。

### 7.4 发布（选择时段）

| 时段 | 适合 |
|---|---|
| 7:00–9:00 | 快讯、早报、通勤轻阅读 |
| 11:30–13:00 | 生活、娱乐、轻松话题 |
| 17:30–19:00 | 解读、行业分析（愿意读长文） |
| 20:00–22:00 | 评论、人物、情绪内容（流量最大） |

### 7.5 黄金 1 小时

- 回复前 5 条评论（让系统看到互动）；
- 转发到朋友圈/社群，拉一批初始阅读；
- 盯点击率：低于 5% 记录问题，别急着删；
- 置顶一条补充信息或争议观点的评论。

### 7.6 复盘（每篇 5 分钟）

只问三个问题：

1. **点击率**低 → 标题/封面哪个拖后腿？（做 A/B 记录）
2. **完读率**低 → 开头第几句流失？（看后台跳出曲线）
3. **互动率**低 → 观点是否太安全？结尾有没有提问？

连续记录 20 篇，就能得到自己账号的「标题母题—点击率」对照表。

## 8. 合规红线（资讯类必读）

### 8.1 资质

- **未取得互联网新闻信息服务许可，不得发布新闻信息**，包括时政、经济、军事、外交等社会公共事务的报道/评论，以及社会突发事件的报道/评论。
- 健康、财经领域需相应资质认证，否则不得发布疾病治疗、用药指导、股票买卖指导、投资指南等。
- 个人号做资讯，安全区是：**产业观察、科技科普、生活方式、公开信息整理 + 个人分析**；危险区是：**时政评论、突发事件、政策解读、荐股**。

### 8.2 内容

- 旧闻新发 / 隐去时间冒充新事件；
- 编造故事、虚构人物对话；
- 洗稿、拼凑、AI 批量生成低质内容；
- 标题与内容不符、封面与标题不符；
- 血腥、猎奇、引人不适；
- 引导互粉、站外引流、二维码/联系方式。

### 8.3 后果

警示 → 扣分 → 禁言 → 限制流量分发 → 封禁 → 关闭营利权限。账号权重下降后，恢复期通常以「月」计。

## 12. 这份调研没解决的问题

1. **没有后台数据**：点击率/完读率区间来自行业经验，不是你账号的真实基线。真正有用的做法是拉自己近 30 篇做中位数。
2. **样本是「频道最新」，不是「爆款榜」**：能说明「平台上在发什么」，不能完全说明「什么一定爆」。若要更严谨，需要连续 7 天、每天固定时点抓取，并按阅读/评论排序。
3. **封面尺寸没有拿到官方最新文档**：文中给的是「横图 + 安全区」的稳健做法，不是精确像素规范；不同客户端位置会有裁切差异。
4. **未做账号级对比**：同一选题下，机构号 vs 个人号的标题/封面差异，值得单独做一次 20 组对照。
