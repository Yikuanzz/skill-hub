## 1. 标题的三个功能

信息流里用户给一条内容的决策时间约 1–1.5 秒。标题要在这 1 秒内完成：

1. **识别**：这是不是我关心的领域？（前 10 字放领域关键词）
2. **缺口**：我还不知道什么？（反差、数字、悬念）
3. **收益**：点开能得到什么？（信息、情绪、谈资、方案）

三个都缺，标题就会“看起来还行，但没人点”。只有缺口没有收益，会变成标题党；只有识别没有缺口，会被当成旧闻划走。

## 2. 八个母题

| 母题 | 结构 | 适合 | 示例 |
|---|---|---|---|
| **反差/递进** | 比 A 更 X 的是 B | 结构性问题、趋势 | 《比学历贬值恐怖的事情出现了！中国正在失控的考研考公内卷在加剧》 |
| **数字+后果** | 主体+动作+具体数字+谁受影响 | 案件、财报、政策 | 《中国首例1000亿骗局！上百万人血本无归，凶手却每天花两万养情妇》 |
| **时间+节点** | 精确时刻+重大动作 | 发射、会议、发布 | 《4时24分准时起飞，中国凌晨达成重大一射，多国宇航员等待上天宫》 |
| **人物+反转** | 名人+没想到+牵连后果 | 国际、娱乐、商业 | 《黄仁勋没想到，自己的私生活风波，意外把36岁女儿“拖入泥潭”》 |
| **设问/解释** | 为什么 A 却 B？ | 解读、科普 | 《为什么马斯克一堆女友却不影响市场，而黄仁勋出轨，市场就塌方？》 |
| **身份/地域代入** | 跟你一样的人+反常识发现 | 社会、生活、职场 | 《在蒙古工作的华人感慨：不要听媒体吹牛，蒙古相当于我国二线城市》 |
| **清单/避坑** | 人群+数字+规则+利益 | 政策、买房、健康 | 《建议大家：今明两年，买房要坚持“买2、买小、不买4”，都是经验》 |
| **直陈快讯** | 主体+动作+数据 | 公告、行情 | 《港股PCB概念股走强 建滔积层板涨近7%》 |

**用法**：一条标题最多组合 **2 个母题**。三个以上会变成信息堆砌，读者扫不完。

## 3. 六个可套用句式

```
① 反差式：[大众认知 A] 的人，为什么在 [具体场景] 输给了 [小人物 B]？
② 递进式：比 [已知坏消息] 更严重的是，[未被注意的结构性问题]
③ 数字式：[主体] 做了 [动作]，[具体数字] 人 / [金额] 受影响
④ 设问式：为什么 [反常现象]？答案藏在 [线索] 里
⑤ 身份式：[跟你一样的人] 在 [时间/地点] 发现：[反常识结论]
⑥ 清单式：[人群] 注意：[N] 个 [坑/信号/变化]，第 [k] 个最容易被忽略
```

填模板时，先确保每个空格都有素材支撑。空格式套话（“真相让人沉默”“背后原因不简单”）属于官方定义的“故弄玄虚”。

## 4. 字数、标点与用词

| 项 | 建议 | 原因 |
|---|---|---|
| 字数 | **20–28 字**为主 | 移动端显示完整；后台上限通常 30 字 |
| 快讯 | 12–18 字 | 信息单一，越短越快 |
| 标点 | 0–2 个 | 「！」「？」「：」各最多 1 个；不要「！！？？」 |
| 数字 | 阿拉伯数字 | 「1000亿」比「一千亿」更快被扫到 |
| 人称 | 至少一个「你/我/他」 | 拉近距离；资讯类慎用「我」 |
| 关键词 | 前 10 字放核心实体 | 算法和用户都先扫前半句 |

**标点的分层用法**
- `：` 用于「观点 + 事实」：《XX 终于表态：一句话，信息量很大》
- `？` 把结论变成待解问题，但正文必须真的回答
- `“”` 给对方贴标签，传播力强但容易滑向低俗，资讯类慎用
- `——` 少用，移动端容易断行

**禁用词**：震惊、必看、速看、不转不是中国人、最、第一、国家级、史上最强。平台明确把夸张、极限用语列为标题党。

## 5. 分领域调整

| 领域 | 标题重心 | 要避免 |
|---|---|---|
| 热点/社会 | 具体人、具体后果、时间地点 | 空泛的“引热议”“炸锅了” |
| 财经 | 数字、同比/环比、谁受影响 | 荐股、收益承诺、绝对化预测 |
| 科技 | 产品/公司+变化+对用户的影响 | 参数堆砌、英文缩写开头 |
| 国际 | 人物+动作+对中国的关联 | 无信源的地缘断言 |
| 娱乐 | 人物+年龄/处境+反转 | 偷拍、隐私、未经证实绯闻 |
| 军事 | 装备/动作+能力变化 | 煽动性战争预言 |
| 生活/健康 | 人群+场景+可执行建议 | 疗效承诺、恐吓式预警 |

## 6. 反例：看起来像爆款，其实不会点

| 反例 | 问题 | 改法 |
|---|---|---|
| 《刚刚，重大利好！》 | 无主体、无信息 | 《XX 下调首付比例，明天起执行》 |
| 《真相曝光，所有人都沉默了》 | 故弄玄虚 | 把“真相”写成一句话 |
| 《关于 XX 的几点思考》 | 像论文，没有缺口 | 把结论前置成判断句 |
| 《XX 事件持续发酵》 | 没有新信息 | 写“新增了什么” |
| 《专家：XX 很重要》 | 无收益、无冲突 | 写“对谁、什么时候、有什么用” |
| 《震惊！XX 竟然这样》 | 极限词+隐瞒信息 | 直接写“XX 做了什么” |

## 7. 7 问自检

1. 去掉形容词，还剩具体信息吗？
2. 标题里的数字/人名/地点，正文能一一对应吗？
3. 有没有一个“我非点不可”的缺口？
4. 是否出现了领域关键词？
5. 是否隐含了正文没有的结论？
6. 读起来像人话，还是像公文/机器翻译？
7. 给一个不关心该领域的人看，他能复述发生了什么吗？

## 8. 生成流程（10 → 3 → 1）

1. 从 `facts.md` 里挑出 **3 个最硬的点**（数字、后果、反差）。
2. 每个点用不同母题写 3–4 条，凑满 **10 条**。
3. 删掉：没有信息量的、正文兑现不了的、需要读者猜的。
4. 留下 **3 条**，必须来自不同母题。
5. 选 **1 条**推荐，写一句“为什么选它”，并标注正文兑现位置（第几段/哪个小标题）。

`titles.md` 建议格式：

```markdown
## 10 条备选
| # | 标题 | 母题 | 字数 | 正文兑现 |
|---|---|---|---|---|
| 1 | ... | 数字+后果 | 26 | 02 节 |

## 3 条入围
1. ...
2. ...
3. ...

## 推荐
**...**
理由：...
风险：...（例如“数字需再确认”）
```
