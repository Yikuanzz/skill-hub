## 1. 通用骨架：钩子—锚点—展开—收束

| 段落 | 字数 | 任务 | 写法 |
|---|---|---|---|
| **钩子** | 60–100 | 让手指停下 | 一句结论 / 一个数字 / 一个场景 / 一句原话 |
| **锚点** | 100–200 | 补全 5W，建立可信度 | 时间、地点、人物、发生了什么、信源 |
| **展开** | 1200–2000 | 给信息增量 | 2–5 节，节长 150–800 字，**不要每节一样长** |
| **收束** | 0–200 | 给判断或问题 | 可以停在一个具体事实上，不必强行升华 |

**信息增量**是什么意思：不只是复述事实，而是回答“为什么发生、意味着什么、接下来会怎样、跟我有什么关系”。平台把“信息增量”写进了首发激励的质量标准。

**骨架不是模板**。短稿可以没有小标题；长稿也不必每节都按“事实—原因—影响”写完。允许一节只写 150 字，下一节写 700 字；允许某一节没有结论。真正要避免的是：每节字数接近、每节段数相同、每节末尾都有一句总结。

## 2. A 快讯（80–300 字）

```
[时间/地点] + [主体] + [动作] + [关键数据]。
[一句背景：为什么重要]
[一句影响：对谁有影响]
[信源]
```

示例（真实）：

> 11月10日，截至发稿，建滔积层板（01888.HK）涨6.88%、广合科技（01989.HK）涨6.21%、胜宏科技（02476.HK）涨5.89%。

要点：
- 没有形容词，靠时效和准确性取胜；
- 数字必须带单位、带时间口径（截至发稿/收盘/同比）；
- 适合机构号、财经号。个人号发纯快讯拼不过机构，要加一句解读。

---

## 3. B 汇编/早报（800–1500 字）

```
导语：今天最值得关注的是 [主线]。
01 [事件] —— 一句话事实 + 一句话解读
02 ...
03 ...
结尾：今天需要盯的一个信号
```

要点：
- 每条 **不超过 120 字**，事实与解读分开（可用不同段落/加粗）；
- 编号连续，不要「一、1、（1）」混用；
- 每条给信源，避免「据悉」「有消息称」；
- 选 5–8 条，不要 20 条；汇编的价值是筛选，不是搬运。

## 4. C 解读（1500–2500 字）

```
钩子：一个反常识结论
锚点：事件 + 时间线
01 发生了什么（事实层）
02 为什么会发生（原因层，2–3 个变量）
03 接下来会怎样（三种情景）
04 对普通人意味着什么（影响层）
收束：我的判断 + 一个开放问题
```

**这不是填空表。** 2–4 节都可以，节长不要一样；原因层可以并进事实层；三种情景如果素材撑不住，就写两种或直接说“看不出来”。不要为了凑齐四节，把一句话拆成三节。

要点：
- 每个小标题都是**一个判断**，不是「背景介绍」；
- 至少给 **1 个别人没说的角度**（数据、历史对照、产业链位置、政策沿革）；
- 三种情景要写清「触发条件」，不要模棱两可；
- 原因层不要超过 3 个变量，多了等于没解释。

**判断句小标题示例**
- ✅「降价不是库存压力，是产能集中释放」
- ✅「真正被挤压的是二线品牌」
- ❌「降价的原因分析」
- ❌「行业背景」

## 5. D 故事化资讯（2000–3000 字，高风险）

```
金句开场
01 场景/人物登场
02 转折（冲突出现）
03 细节（数字、对话、时间点）
04 代价/后果
05 反思（作者视角）
收束：金句 + 互动
```

要点：
- 用「时间 + 地点 + 具体数字」建立真实感，但**所有细节必须来自素材**；
- 中段可以引入第二、第三个案例，把个案扩展成趋势，但要分别标信源；
- 结尾落到「制度/平台/个人选择」，再引导互动；
- 开头或结尾标注「个人观点，仅供参考」；文末列信源。

**必须做的三件事**
1. 区分「已确认事实 / 媒体转述 / 网络猜测」；
2. 不用真实姓名编造对话；
3. 不把 overseas 匿名爆料写成定论。

**适合**：有当事人采访、有明确时间线、有独特细节的素材。
**不适合**：只有一条通稿、只有网友评论、只有截图。

## 6. 开头 7 式

1. **结论前置**：`这次降价的真正原因不在库存。`
2. **数字冲击**：`423 万人报名，只招 3.5 万。`
3. **场景切入**：`昨天下午，杭州一位店主把最后一批货搬上了货车。`
4. **引语开场**：`“我们也没想到会这么快。”一位接近交易的人士说。`
5. **反差设问**：`为什么越努力的人，反而越容易被裁？`
6. **时间锚点**：`11 月 8 日深夜，一封内部邮件改变了英伟达的舆论走向。`
7. **利益相关**：`如果你明年打算买房，这条政策会直接影响你的首付。`

**开头三不要**
- 不要「随着……的发展」；
- 不要先讲行业史；
- 不要在 100 字内出现两个以上陌生概念。

## 7. 结尾 4 式

| 类型 | 写法 | 适用 |
|---|---|---|
| **判断式** | 「短期看……，长期看……，真正的变量是……」 | 解读、财经 |
| **提问式** | 「如果是你，会怎么选？」 | 社会、情感 |
| **行动式** | 「接下来 3 天，重点盯这三个信号」 | 政策、市场 |
| **金句式** | 一句可被截图转发的话 | 人物、评论 |

资讯类最忌讳：「以上就是全部内容，欢迎关注」。要么给判断，要么给问题。

## 8. 节奏与排版

- 每段 **1–6 行**，长短交错；不要每段都写成三行。
- 短稿可以没有小标题；长稿 **2–5 节**，节长不要一样，允许 150 字和 700 字并存。
- 小标题用**动词或判断**开头：`降价潮开始了` / `谁在买单` / `真正的风险在明年`。
- 全文 **2–3 个真正的转折**（真相、反例、数字、引语），不要每节都收一次。
- 长文每 800–1000 字插一张图；短图文 3–6 张。
- 加粗只给三类内容：核心结论、关键数字、转折句。通篇加粗等于没加粗。
- 列表用于并列信息，不要用列表写叙事。
- **不要默认写“写在最后”**。最后一段可以直接停在事实、数字或一句没回答的问题上。

## 9. 四类结构怎么选

| 素材特征 | 选 |
|---|---|
| 一条公告/一组数据，无背景 | A 快讯 |
| 多条独立信息，需要筛选 | B 汇编 |
| 有因果、有背景、有判断 | C 解读 |
| 有人物、有细节、有时间线 | D 故事化 |
| 信源弱但话题热 | 降级为 C，标题别定论 |
| 没有一手信息，只有网传截图 | 不做 D；做「已知/未知」信息整理 |

> 选择顺序：**信源强度 > 信息量 > 账号人设 > 流量预期**。反过来选，迟早出事。
